01 / 시작

UI를 실제 문맥에서 확인합니다.

각 모듈을 전시 카드 안에 넣지 않고, 실제 페이지 흐름에 놓아 여백과 반응형 배치를 함께 확인합니다.

더미 본문

콘텐츠 길이와 주변 요소가 달라져도 UI가 자연스러운지 봅니다.

이 텍스트는 운영 콘텐츠가 아닙니다. 문장 길이, 제목 줄바꿈, 섹션 간격을 검증하기 위한 샘플입니다.

일반 본문 예시

모듈의 크기만 따로 보는 대신 위아래 콘텐츠와 맞닿았을 때의 밀도와 시선을 확인합니다.

PC와 모바일 모두 같은 더미 구조를 사용하므로 개발자 도구로 별도 화면을 조립하지 않아도 됩니다.
