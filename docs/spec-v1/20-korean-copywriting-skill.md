# WORK-COPY — 한국어 카피라이팅 스킬 계약

Photo-eBook에서 한국어 문장을 새로 쓰거나 고칠 때 적용하는 강제 규칙이다. 단순 맞춤법 교정이 아니라 **한국의 서비스 기획자·콘텐츠 기획자가 실제 화면에 쓰는 문장 리듬**을 기준으로 한다.

## WORK-COPY-001 — 적용 순서

한국어 카피 작업 전 아래 순서로 확인한다.

1. Google Sheet `COPY_GUIDE` 탭의 최신 규칙을 읽는다.
2. 이 문서를 읽는다.
3. 사용자에게서 직접 받은 전후 문장 예시가 있으면 그것을 최우선 기준으로 삼는다.
4. 외부 한국어 스킬은 보조 기준으로 사용한다.
5. 사실, 수치, 가격, 기간, 모델명, 기능 조건은 카피 윤문 과정에서 바꾸지 않는다.

외부 참고:
- DaleSeo/korean-skills: https://github.com/DaleSeo/korean-skills
- 프로젝트 `COPY_GUIDE`에 기록된 korean-humanizer / KatFishNet / 한국어 style-guide 계열 규칙

## WORK-COPY-002 — 프로젝트 문체

- 번역문처럼 설명하지 말고, 사용자가 **무엇을 결정하고 무엇을 하면 되는지** 먼저 이해되게 쓴다.
- 짧은 표제어, 설명 문장, 행동 문장을 문맥에 맞게 섞는다.
- 모든 문장을 같은 길이와 같은 종결어미로 맞추지 않는다.
- `~을 봅니다`, `~을 한다`, `~을 익힌다`, `~할 수 있습니다`가 연속되면 다시 쓴다.
- 한국어로 소리 내어 읽었을 때 한 호흡이 길면 문장을 나누거나 자연스러운 위치에 쉼표를 둔다.
- 영어식 콜론과 쉼표 나열을 습관적으로 사용하지 않는다.
- 모바일에서 조사 한 글자나 짧은 단어만 다음 줄로 떨어지지 않도록 의미 단위 줄바꿈을 설계한다.
- 자연스러운 기존 문장은 괜히 다시 쓰지 않는다. AI 티가 강하거나 오해가 생기는 부분만 고친다.

## WORK-COPY-003 — 금지에 가까운 반복 패턴

아래 패턴은 문맥상 꼭 필요하지 않으면 피한다.

- 방어형 대비: `~이 아니다. ~이다.`
- 기계적 시작어: `먼저 ~`, `처음부터 ~`를 제목마다 반복
- 추상 비교: `학위보다 실무`, `사진 모음보다 납품 사례`처럼 기준과 행동이 빠진 비교형 제목
- 기계적 서술: `~을 봅니다`, `~을 확인합니다`, `~을 익힌다`의 반복
- 번역투: `~에 대해`, `~을 통해`, `~에 의해`, 불필요한 피동
- 맥락 없는 조언: `숫자를 외우기보다`처럼 무엇을 왜 해야 하는지 빠진 표현
- 과장된 추상어: `혁신적`, `압도적`, `효과적`, `스마트한` 등 구체 정보 없이 분위기만 만드는 단어

## WORK-COPY-004 — 포트폴리오 표현

실제 고객 의뢰가 아닌 포트폴리오 촬영은 `가상 의뢰`, `실제 의뢰처럼 보이는 프로젝트`로 표현하지 않는다.

권장 구조:

`자체 기획 촬영임을 명시 → 촬영 목적 → 예상 사용처 → 준비/촬영 과정 → 최종 결과물`

실제 고객 작업은 자체 기획 촬영과 구분해 표시한다. 사용자가 경력을 오해할 수 있는 문장을 만들지 않는다.

## WORK-COPY-005 — 제목과 줄바꿈

제목은 브라우저 자동 줄바꿈에만 맡기지 않는다. 의미가 분명한 제목은 PC와 모바일에서 같은 의미 단위가 유지되도록 의도적인 줄바꿈을 사용할 수 있다.

확정 예시:

```text
상업사진은
‘잘 찍기’와 ‘빨리 납품하기’를
같이 연습해야 합니다.
```

```text
사진으로 먹고살기,
첫 12개월
```

줄바꿈을 넣었을 때 좁은 화면에서 단어가 잘리거나 가로 스크롤이 생기면 `nowrap`으로 억지 고정하지 않는다. 의미 단위를 유지하면서 폭에 맞게 검수한다.

## WORK-COPY-006 — 사용자 확정 전후 예시

아래 방향을 프로젝트 기준으로 유지한다.

- `먼저 팔리는 분야 고르기` → `잘 팔리는 분야를 고르세요`
- `반복 주문이 생기고 단가를 올리기 쉬운 세 분야만 본다.` → `내 주변에서 반복 주문이 생기고, 단가를 올리기 쉬운 세 분야를 추려보는 것이 중요합니다.`
- `학위보다 매출까지 걸리는 시간을 봅니다.` → `실제 매출 발생까지 걸리는 시간을 계산해보세요.`
- `국비 학원은 간판보다 수업 내용을 봅니다` → `국비지원 학원은 실제 수업 내용을 면밀히 살펴보세요.`
- `처음 사는 것과 나중에 사는 것을 분리합니다.` → `처음 살 것과 나중에 살 것을 명확히 구분하는 게 좋습니다.`
- `사진 모음보다 ‘실제 의뢰처럼 보이는 프로젝트’를 만드세요.` → 자체 기획 촬영임을 밝히고 목적·사용처·과정·결과물을 보여주는 문장으로 수정
- `숫자를 외우기보다 ...` → 같은 장면을 여러 번 촬영하고 초점·노출·거리·빛의 차이를 직접 비교하도록 구체 행동으로 수정

Hero 확정 방향:

```text
사진으로 먹고살기,
첫 12개월

국비로 배우고, 필요한 최소 장비를 구매하고, 재구매 고객을 만들어보세요.
월 순수익 300만 원까지 도전해보는 왕초보를 위한 기초 전략.
```

## WORK-COPY-007 — Google Sheet가 원본

사이트 본문 카피의 canonical source는 Google Sheet다.

- `CONTENT_DB`, `NAV_MODULES`, `GUIDE_COPY`, `PHOTO_LESSONS`, `PORTFOLIO`, `EDUCATION`, `SKILLS` 등 원본 셀을 우선 수정한다.
- 화면에만 임시 DOM 패치를 하고 원본 데이터를 방치하지 않는다.
- 첫 화면 캐시/번들 때문에 구버전 문장이 보일 수 있으면 source 수정과 함께 런타임 호환 레이어를 갱신한다.
- 런타임 호환 레이어는 새로운 카피 저장소가 아니라, 구형 하드코딩·캐시·의도적 `<br>`를 맞추는 용도로만 사용한다.

## WORK-COPY-008 — 배포 전 검수

최소 다음을 확인한다.

- 소리 내어 읽었을 때 한국어 호흡이 자연스러운가
- 제목과 설명이 같은 말을 반복하지 않는가
- `먼저`, `~보다`, `~이 아니다`, `~을 봅니다` 같은 패턴이 연달아 나오지 않는가
- 사용자가 해야 할 행동이나 판단 기준이 구체적인가
- 실제 의뢰와 자체 기획 촬영을 혼동시키지 않는가
- 수치와 사실이 원문에서 바뀌지 않았는가
- PC와 모바일의 제목 줄바꿈이 의미 단위를 깨지 않는가
- 버튼/탭 레이블은 짧고 즉시 이해되는가

이 규칙은 신규 카피 작성, 기존 문장 수정, AI 초안 검수 모두에 적용한다.
