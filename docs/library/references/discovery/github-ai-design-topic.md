## Why it matters

특정 구현 하나를 참고하는 저장소가 아니라 AI 디자인 도구, design-system 추출, agent skill, prototype/editor 계열의 새로운 프로젝트를 계속 발견할 수 있는 탐색 출발점이다.

## 참고할 것

- 새로운 AI design tool과 agent skill 후보를 찾는 discovery source로 사용
- design-to-code, local-first editor, DESIGN.md generator, AI interaction taxonomy처럼 현재 Reference Library에 없는 영역을 탐색
- 후보를 발견하면 개별 repository를 따로 검토한 뒤 정식 reference entry로 승격

## 적용 후보

- Reference Library 정기 보강
- 관리자 Block Editor를 만들 때 유사한 open-source editor 조사
- DESIGN.md / design token / AI prototype workflow 조사

## 적용하지 않을 것

- topic에 등록됐다는 이유만으로 품질을 보증하지 않음
- stars나 최신 업데이트만으로 바로 production dependency를 선택하지 않음
- topic 페이지 자체를 디자인 규칙이나 구현 authority로 사용하지 않음

## 기술 의존성

없음. discovery index로만 사용한다.

## 라이선스

해당 없음. 개별 repository의 라이선스를 각각 확인한다.

## Integration rule

1. 여기서 발견한 repository는 목적, 유지보수 상태, 라이선스, 기술 의존성을 별도 검토한다.
2. 실제로 채택할 가치가 있는 경우 `docs/library/references/`에 독립 entry를 만든다.
3. discovery 결과를 대화 기록에만 남기지 않는다.
