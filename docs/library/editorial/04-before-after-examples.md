# 04. Approved Before / After Examples

이 문서는 추상적인 스타일 설명보다 실제 프로젝트에서 어떤 문장을 피하고 어떤 방향을 승인했는지 보여준다.

새 분야를 작성할 때 사진이라는 단어 자체를 복제하지 말고 **수정 원리**를 적용한다.

## 예시 01 — 추상 비교 → 실제 판단

Before:
`학위보다 매출까지 걸리는 시간을 봅니다.`

Approved direction:
`실제 매출 발생까지 걸리는 시간을 계산해보세요.`

원리:
- 추상적인 `A보다 B` 대비를 줄인다.
- 사용자가 실제로 할 판단을 동사로 말한다.

## 예시 02 — 모호한 기준 → 확인 항목

Before:
`국비 학원은 간판보다 수업 내용을 봅니다.`

Approved direction:
`국비지원 학원은 실제 수업 내용을 면밀히 살펴보세요.`

추가로 좋은 block에서는 실습 시간, 강사 최근 작업, 수강생 결과물, 견적·납품 교육처럼 확인 기준을 아래 항목으로 보여준다.

## 예시 03 — 기계적 제목 → 자연스러운 행동

Before:
`먼저 팔리는 분야 고르기`

Approved:
`잘 팔리는 분야를 고르세요`

원리:
- `먼저`를 제목마다 반복하지 않는다.
- 사용자가 해야 할 행동을 바로 말한다.

## 예시 04 — 짧지만 정보 부족 → 판단 기준 추가

Before:
`반복 주문이 생기고 단가를 올리기 쉬운 세 분야만 본다.`

Approved direction:
`내 주변에서 반복 주문이 생기고, 단가를 올리기 쉬운 세 분야를 추려보는 것이 중요합니다.`

원리:
- 무엇을 기준으로 고르는지 보완한다.
- 선언형 문장을 실제 상황과 연결한다.

## 예시 05 — 불분명한 구매 시점 → 명확한 구분

Before:
`처음 사는 것과 나중에 사는 것을 분리합니다.`

Approved:
`처음 살 것과 나중에 살 것을 명확히 구분하는 게 좋습니다.`

원리:
- 행정문처럼 들리는 표현보다 실제 조언의 어감을 사용한다.

## 예시 06 — 자체 기획을 고객 의뢰처럼 보이게 하는 표현 금지

Before:
`사진 모음보다 ‘실제 의뢰처럼 보이는 프로젝트’를 만드세요.`

Approved direction:
자체 기획 촬영임을 밝히고, 촬영 목적·예상 사용처·과정·결과물을 보여준다.

원리:
- 실제 경력을 오해하게 만들지 않는다.
- 포트폴리오의 설득력은 위장보다 목적과 과정에서 만든다.

## 예시 07 — 추상 조언 → 실제 연습

Before:
`숫자를 외우기보다 결과를 확인하세요.`

Approved:
`같은 장면을 여러 번 찍고 초점, 노출, 거리, 빛의 차이를 직접 비교해보세요.`

원리:
- 사용자가 바로 실행할 수 있는 행동으로 바꾼다.
- 무엇을 비교해야 하는지 구체적으로 적는다.

## 예시 08 — 주체와 동작

피하기:
주체가 흐리고 추상 명사가 이어지는 설명

Approved direction:
`사진가는 사진을 찍고, 고객을 만나고, 상품을 만든다.`

원리:
- 누가 무엇을 하는지 바로 보이게 쓴다.
- 산업이 바뀌면 실제 작업 동사로 교체한다.

## 예시 09 — 표현 선택

Less preferred:
`사진가는 촬영만 잘하면 안 된다.`

Preferred:
`사진가는 촬영만 잘해서는 안 된다.`

원리:
- 문법적으로 가능한 표현 중에서도 실제 한국어 기획 문장에 더 자연스러운 것을 고른다.
- 의미 강도를 바꾸지 않는다.

## 예시 10 — AI식 브랜드 문구

피하기:
- `~을 넘어`
- `단순히 ~이 아니라`
- `시각적 언어`
- `진정성 있는 브랜드`
- `사진의 가치를 확장하다`

Approved direction:
누가 어떤 작업을 하고, 고객에게 어떤 결과물을 주며, 비용·시간·성과가 어떻게 달라지는지 구체적으로 설명한다.

## 예시 11 — 제목과 설명 역할 분리

피하기:
본문처럼 길고 모든 조건을 포함한 제목

Approved direction:
- 제목: 짧은 핵심 문구
- 설명: 기준과 이유
- 카드/리스트: 세부 조건

제목 끝에는 마침표를 붙이지 않는다.

## 예시 12 — CTA

피하기:
추상적인 응원이나 분위기만 만드는 마무리

Approved direction:
`지금, 당신의 포트폴리오를 점검해보자.`

제품 UI의 버튼 레이블은 더 짧게:
`포트폴리오 점검`

## 예시 13 — 의미 단위 줄바꿈

Approved example:

```text
상업사진은
‘잘 찍기’와 ‘빨리 납품하기’를
같이 연습해야 합니다.
```

원리:
- 조사나 짧은 단어만 새 줄에 남지 않게 한다.
- `nowrap`으로 억지 고정하지 않는다.
- PC와 모바일에서 의미가 같은 덩어리로 읽히는지 확인한다.

## 이 문서 갱신 규칙

사용자가 실제 화면에서 문장을 수정해 최종 방향을 확정하면, 재사용 가치가 있는 사례는 이 문서나 해당 industry editorial profile에 추가한다.

모든 피드백을 예시로 쌓지 않는다. 다른 분야에도 적용할 수 있는 원칙이 드러난 사례를 우선한다.
