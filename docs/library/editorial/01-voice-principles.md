# 01. Platform Voice Principles

## VOICE-001 — 기획 문장

이 플랫폼의 글은 정보를 늘어놓는 설명서보다 사용자의 판단과 실행을 돕는 기획 문장에 가깝게 쓴다.

좋은 문장의 기본 순서:

`누가/무엇이 → 무엇을 한다 → 어떤 기준이나 결과를 본다`

주체가 필요 없는 짧은 UI 문장은 예외지만, 본문에서 주어와 동작이 모두 흐려지면 추상어로 메우지 않는다.

## VOICE-002 — 구체적인 명사와 동사

분위기만 만드는 표현보다 실제 대상과 행동을 쓴다.

피하기:
- 혁신적
- 압도적
- 스마트한
- 포괄적
- 효과적
- 시각적 언어
- 진정성 있는 브랜드
- 가치를 확장하다

필요할 때는 무엇이 왜 좋은지 가격, 시간, 수량, 작업, 고객, 결과물처럼 확인 가능한 말로 바꾼다.

## VOICE-003 — AI식 대비 금지

다음 구조를 습관적으로 사용하지 않는다.

- `~이 아니다. ~이다.`
- `단순히 ~이 아니라`
- `~을 넘어`
- `A보다 B`

대비 자체가 필요한 경우에는 무엇이 어떻게 다른지 실제 기준을 보여준다.

예:

피하기: `학위보다 실무가 중요합니다.`

권장 방향: `교육 과정을 고를 때는 실제 촬영 시간, 강사의 최근 작업, 수강생 결과물, 견적·납품 교육 여부를 같이 확인하세요.`

## VOICE-004 — 기계적인 시작과 끝 금지

제목마다 `먼저`, `처음부터`를 반복하지 않는다.

본문의 종결도 `~을 봅니다`, `~을 확인합니다`, `~을 익힌다`, `~할 수 있습니다`가 이어지지 않게 문맥에 맞춰 섞는다.

짧은 명사형 제목, 설명 문장, 직접 행동 문장을 필요한 위치에 사용한다.

## VOICE-005 — 제목

- 짧은 명사형 또는 짧은 핵심 문구를 우선한다.
- 제목 끝에 마침표를 붙이지 않는다.
- 제목에서 모든 설명을 끝내려고 하지 않는다.
- 긴 조건과 근거는 아래 설명문으로 내린다.
- PC와 모바일 모두 의미 단위가 유지되도록 줄바꿈을 검토한다.

## VOICE-006 — 본문 호흡

- 한 문장에 핵심 행동이나 판단을 하나씩 둔다.
- 소리 내어 읽었을 때 한 호흡이 지나치게 길면 나눈다.
- 영어식 쉼표와 콜론 나열을 습관적으로 사용하지 않는다.
- 모든 문장을 같은 길이로 만들지 않는다.
- 한국어 문장이 자연스럽다면 굳이 다시 쓰지 않는다.

## VOICE-007 — 표현 선택

문법적으로 틀리지 않았다는 이유만으로 어색한 표현을 유지하지 않는다. 한국의 서비스·콘텐츠 기획 문서에서 실제로 읽기 편한 표현을 고른다.

표현을 고칠 때 사실이나 주장 강도를 몰래 바꾸지 않는다.

## VOICE-008 — 직접 행동

사용자가 해야 할 일이 있는 블록은 행동을 바로 말한다.

추상적인 응원 문구나 의미 없는 마무리를 넣지 않는다.

CTA는 동작이 분명해야 한다.

예:
- 견적표 확인
- 교육 과정 비교
- 포트폴리오 점검
- 출처 보기

본문형 CTA에서는 문맥에 따라 자연스러운 완문을 사용할 수 있다.

## VOICE-009 — 중복과 수식어

같은 정보를 제목, 설명, 카드 본문에서 세 번 반복하지 않는다.

정보는 다음 순서로 정리한다.

1. 지금 알아야 할 핵심
2. 판단 기준
3. 구체 예시나 수치
4. 다음 행동

새로운 정보가 없으면 문장을 늘리지 않는다.

## VOICE-010 — 새 용어

초보자를 위한 플랫폼이므로 전문용어는 필요하면 쓸 수 있다. 다만 사전 정의부터 길게 설명하지 않는다.

먼저 현재 화면에서 그 용어가 무엇을 바꾸는지 설명하고, 필요한 경우 그다음에 정확한 정의를 붙인다.

## VOICE-011 — 사실 잠금

문체 수정만 하는 작업에서는 다음을 변경하지 않는다.

- 가격과 금액
- 날짜와 기간
- 수량과 비율
- 제품/모델명
- 회사·기관·인명·지명
- 법률/제도 조건
- 직접 인용
- 출처의 의미

사실 자체가 틀렸다고 의심되면 문장 윤문과 분리해서 검증 상태를 표시한다.

## VOICE-012 — 사용자 작성 내용 보호

관리자 Block Editor에서는 사용자가 직접 작성한 필드에 잠금 상태를 둘 수 있어야 한다.

권장 상태:
- `ai_edit: full`
- `ai_edit: wording_only`
- `ai_edit: fact_check_only`
- `ai_edit: locked`

AI는 `locked` 내용을 변경하지 않는다.

## VOICE-013 — 포트폴리오·사례의 진실성

자체 기획 작업을 실제 고객 의뢰처럼 보이게 쓰지 않는다.

자체 기획 사례는 다음을 명확하게 보여준다.

`자체 기획임을 표시 → 목적 → 예상 사용처 → 준비/과정 → 결과물`

실제 고객 사례와 시각적으로나 문장으로 구분한다.

## VOICE-014 — 산업 독립 규칙

이 문서의 규칙은 사진뿐 아니라 영상편집, 네일, 애견미용, 소규모 창업 등 새로운 pack에도 기본 적용한다.

분야 특수 용어, 법적 조건, 작업 관행은 해당 pack의 별도 editorial profile로 추가하고 이 공통 규칙을 덮어쓰지 않는다.
