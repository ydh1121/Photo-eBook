# Global Image Generation Rules V1

이 파일은 사진 분야에만 종속되지 않는 상위 규칙이다. 향후 플랫폼이 뷰티, 교육, 헬스, 커머스 등 다른 산업으로 확장돼도 그대로 유지하고 산업별 규칙을 하위에 추가한다.

## GLOBAL-IMG-001 — Context first

이미지 생성 전에 반드시 해당 슬롯의 챕터 제목, 섹션 제목, 본문 설명, 카드 제목, 강조문장, CTA 또는 지표를 읽는다. 단순 카테고리 키워드만 보고 이미지를 만들지 않는다.

이미지는 주변 문장을 보조해야 한다. 예를 들어 본문이 ‘반복 주문 구조’를 설명하는데 단순히 카메라를 든 사람만 보여주는 것은 부적합하다.

## GLOBAL-IMG-002 — 한 이미지, 한 역할

모든 슬롯은 다음 중 하나의 1차 역할을 갖는다.

- 실제 과정을 설명
- 목표 결과물을 보여줌
- 해당 챕터의 환경과 맥락을 설정
- 실제 제품/자료를 정확히 식별
- 외부 이미지 실패 시 안전한 fallback 제공

정보 역할이 없는 장식 이미지는 생성하지 않는다.

## GLOBAL-IMG-003 — 반복 금지

관련 없는 슬롯끼리 같은 장면, 같은 사람, 같은 카메라 앵글, 같은 소품 배치, 같은 제품을 재사용하지 않는다.

같은 챕터 내에서는 색감과 촬영 언어를 맞출 수 있지만, 각 슬롯은 한눈에 다른 내용을 설명해야 한다.

## GLOBAL-IMG-004 — 기본 스타일

기본값은 사실적인 editorial photography 또는 realistic commercial photography다.

금지:
- 명백한 AI 질감
- 과한 HDR
- 플라스틱 피부
- 손가락/손 형태 오류
- 중복된 물체
- 물리적으로 말이 안 되는 반사
- 이유 없는 시네마틱 연무
- 의미 없이 강한 teal/orange grading

## GLOBAL-IMG-005 — 사실성이 필요한 대상

특정 실제 제품, UI, 장소, 규정, 브랜드 오브젝트처럼 식별 정확도가 중요한 슬롯은 `reference_required`로 분류한다.

신뢰할 수 있는 참조 없이 실제 제품을 비슷하게 상상해서 생성하는 것은 금지한다.

## GLOBAL-IMG-006 — 이미지 안의 텍스트

생성 이미지 안에 읽어야 하는 문장을 넣지 않는다. 가격, 법적 문구, 차트 수치, UI 라벨, 파일명, 로고 등의 정보는 HTML이 담당한다.

화면이 필요한 장면은 구조만 보이고 텍스트는 읽히지 않는 수준으로 처리한다.

## GLOBAL-IMG-007 — 사람

사람은 자연스러운 표정과 자세를 사용한다. 과장된 광고 표정이나 전형적인 스톡사진 포즈를 피한다.

한국 사용자에게 실제 업무 환경을 설명하는 장면이라면 한국의 사무실, 카페, 스튜디오, 소규모 사업장과 자연스럽게 맞는 인물을 우선한다. 사람 자체가 필요하지 않은 장면에는 억지로 인물을 넣지 않는다.

## GLOBAL-IMG-008 — UI crop 우선

프롬프트는 최종 CSS crop을 기준으로 작성한다.

- `object-fit:cover` 슬롯은 주요 피사체를 안전영역 안에 둔다.
- 텍스트 오버레이가 있는 히어로는 카피가 올라갈 영역을 복잡하게 만들지 않는다.
- 모바일 카드에서 인지가 어려운 작은 디테일을 중심 주제로 삼지 않는다.

## GLOBAL-IMG-009 — 시리즈 일관성

같은 시리즈는 대비, 화이트밸런스, 현실감, 카메라 언어를 공유한다. 그러나 장면 자체는 복제하지 않는다.

## GLOBAL-IMG-010 — 모바일 가독성

작은 화면에서도 무엇을 보여주는 이미지인지 즉시 알아볼 수 있어야 한다. 한 장면에 주제가 너무 많으면 실패다.

핵심 의미를 미세한 색 차이만으로 전달하지 않는다.

## GLOBAL-IMG-011 — 출력 형식

프로덕션 기본 형식은 WebP다.

권장값:
- 메인/챕터 히어로: long edge 1600px 이상, 목표 280KB 이하
- 일반 카드: long edge 1200px 이상, 목표 160KB 이하
- 제품 식별 카드: 1000px square 이상, 목표 140KB 이하
- 큰 레슨 이미지: long edge 1400px 이상, 목표 200KB 이하
- WebP quality: 대체로 80~86 범위에서 육안 검수
- 불필요한 metadata 제거

생성기는 PNG/JPEG를 출력해도 되지만 최종 배포 파일은 지정된 경로의 WebP로 변환한다.

## GLOBAL-IMG-012 — 파일명과 경로

파일명과 경로는 생성 시 임의로 만들지 않는다. `manifest.json`과 `public/assets/image-slots-v1.js`에 지정된 경로가 유일한 기준이다.

## GLOBAL-IMG-013 — source class

- `generate`: 새 contextual asset 생성
- `reference_required`: 정확한 참조가 있을 때만 생성/정규화
- `preserve_external`: 실제 OG/thumbnail 등 원문 자산을 그대로 사용
- `fallback_generate`: 외부 이미지가 없을 때만 사용

## GLOBAL-IMG-014 — 생성 성공 ≠ 승인

아래를 모두 통과해야 `ready:true`가 된다.

1. 본문 맥락 일치
2. 실제 UI crop 적합
3. 현실감
4. 다른 슬롯과 중복되지 않음
5. 기술 품질
6. WebP 용량
7. 라이트/다크 UI에서 카드 경계와 이미지가 자연스러움

## GLOBAL-IMG-015 — 다른 산업으로 확장할 때

상위 규칙은 유지한다. 새 산업은 `industry-<name>-rules.md`를 추가한다. 특정 산업 때문에 상위 규칙을 느슨하게 바꾸지 않는다.

## 프롬프트 조립 순서

실제 생성 입력은 다음 순서로 해석한다.

`GLOBAL RULES → INDUSTRY RULES → SLOT CONTEXT → SLOT PROMPT → AVOID LIST → OUTPUT/CROP REQUIREMENTS`
